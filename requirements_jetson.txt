# IMPORTANT: PyTorch and CUDA are already included in JetPack -> do NOT pip install torch here

#
# onnxruntime-gpu for Jetson requires the NVIDIA-provided wheel, NOT the standard PyPI version
# the normal "pip install onnxruntime-gpu" wont work on jetson - it needs the arm64 jetpack build
# download the correct wheel from: https://elinux.org/Jetson_Zoo#ONNX_Runtime
# then install manualy with: pip install onnxruntime_gpu-*.whl
